# ユーザーガイド（日本語）

## インストール

* **インストーラー**: `BetterGFNNeuralSetup.exe` を実行 → 「次へ」→ 完了。管理者権限は不要で、
  `%LOCALAPPDATA%\Programs\Better GFN Neural` にインストールされ、スタートメニューとデスクトップにショートカットが作成されます。
* **ポータブル版**: `BetterGFNNeural-1.0.0-portable.zip` を任意のフォルダに展開し、`BetterGFNNeural.exe` を実行。
  設定とログは同じフォルダに保存されます（`portable.dat` があるため）。
* 署名されていないため、初回起動時に Windows SmartScreen の警告が出る場合があります（「詳細情報」→「実行」）。

## 初回起動

5 つのチェックが自動で進みます: GPU の確認 → モニターの確認 → GeForce NOW の検出 → オートモード設定 → 完了。
「はじめる」を押せば終わりです。以降は何もする必要はありません。

## 普段の使い方

1. Better GFN Neural を起動したままにする（閉じるボタンでタスクトレイに格納されます）
2. GeForce NOW でゲームを開始する
3. GeForce NOW のウィンドウが前面にある間、強化された映像がその上に表示されます

| トレイアイコン | 意味 |
|---|---|
| 灰色のリング | 待機中（GeForce NOW 未起動） |
| 青紫 | 接続済み（GeForce NOW 起動中、ゲームなし） |
| ミントグリーン | 強化中 |
| オレンジのリング | 一時停止中 |

トレイアイコンの右クリックで「開く / 一時停止・再開 / GeForce NOWを起動 / 終了」ができます。

## 画面の説明

* **ホーム**: GFN ステータス、現在のゲーム、強化状態、オートモード、出力解像度、出力 FPS、遅延、GPU、プリセットとフレーム補間のクイック設定
* **画質強化**: 上級者向けの詳細設定（Neural Super Resolution、圧縮ノイズ除去、時間方向再構成、デブラー、シャープ、フレーム補間、HDR+/カラー）
* **ディスプレイ**: 出力モード（自動 / GFN ウィンドウに合わせる / フルスクリーン）、出力解像度、比較表示、キャプチャ方式、モニター一覧（解像度・リフレッシュレート・HDR・VRR）
* **ゲーム**: ゲームごとのプロファイル（自動作成）。プリセット、パフォーマンス優先度、全画質設定を保存
* **パフォーマンス**: 入力/出力/キャプチャ FPS、解像度、処理時間、GPU 使用率、VRAM、フレーム時間、アップスケール方式、フレーム補間、ドロップフレーム、追加処理遅延、ステージ別 GPU 時間、グラフ
* **ベンチマーク**: 「ベンチマークを実行」→ 推奨プリセット・出力解像度・フレーム補間を表示 →「推奨設定を適用」
* **設定**: Windows 起動時に開始、バックグラウンド起動、トレイ格納、自動開始、通知、言語、GeForce NOW の場所、ログ、コントローラー、リセット

## 表示言語（日本語 / English / 日本語 + English）

画面右上のタイトルバーにある **「日本語 | English | 日本語 + EN」** をクリックすると、その場で表示言語が切り替わります（設定 → 言語 でも変更可）。

| 設定 | 表示 |
|---|---|
| 日本語 | すべて日本語で表示 |
| English | すべて英語で表示 |
| 日本語 + English | 日本語で表示し、見出し・項目名・メニューに英語の原文を小さく併記 |
| 自動（初期値） | Windows の表示言語が日本語なら「日本語 + English」、それ以外は「English」 |

エンジンの状態表示、オートモードの判断理由、キャプチャのエラー、ベンチマークの進捗なども翻訳されます。ログファイルは調査しやすいよう常に英語で記録されます。

## プリセット

| プリセット | 説明 |
|---|---|
| Auto（推奨） | オートモードが全 7 段階から最適な品質を自動選択 |
| Ultra | 最高品質（NSR-L、高品質デノイズ・デブラー・時間方向強化・HDR+・カラー強化）から開始。不足時は自動で下げる |
| Quality | 高品質（最大ティア 5） |
| Balanced | バランス（最大ティア 4） |
| Performance | 軽量（最大ティア 2） |
| Low Latency | 遅延最優先（フレーム補間なし、最小バッファ） |

## 低スペック PC で快適に遊ぶには

- プリセットは **Auto**（迷ったらこれ）。遅延を最優先したいときは **Low Latency**。
- 内蔵 GPU でもティア 1〜2 で **NSR-T（軽量 AI 超解像）** が動きます。単純拡大より輪郭や文字がくっきりします。
- **カクつき補完**（画質強化 / ホーム）は ON のままがおすすめ。回線の揺らぎでフレームが遅れたときに映像が止まって見えるのを防ぎます。遅延は増えません。
- フレーム補間は **Auto** 推奨。GPU に余裕があり遅延予算内のときだけ有効になります。
- ノート PC はバッテリー駆動中に自動で品質を下げます（設定 → 電源）。
- ゲーム内オーバーレイ（OSD、ディスプレイ ページ）を ON にすると、FPS・処理時間・追加遅延をプレイ中に確認できます。

## よくある質問

**Q. ホットキーはありますか？** — ありません。すべて自動で、設定は GUI からのみ変更します。

**Q. マウスやコントローラーの操作は大丈夫？** — 出力ウィンドウはクリック透過・フォーカスを奪わない設計で、入力はすべて GeForce NOW に直接届きます。コントローラーは検出表示のみで、デバイスを開くことはありません。

**Q. ウィンドウ表示の GeForce NOW がモニター全体に拡大された** — 出力モードが「自動」のとき、GeForce NOW がウィンドウ表示ならモニター全体へアップスケールします。通常のウィンドウ表示にしたい場合は「ディスプレイ → 出力モード → GFN ウィンドウに合わせる」を選んでください。Alt+Tab でいつでも他のアプリに切り替えられます。

**Q. 画質の違いを確認したい** — 「ディスプレイ → 比較表示」をオンにすると、画面左半分が元映像、右半分が強化後になります。

**Q. 映像が黒い** — GeForce NOW またはゲーム側がキャプチャを禁止している可能性があります（本アプリは保護を回避しません）。トレイから一時停止してください。

**Q. 動作が重い** — オートモードが自動で品質を下げますが、「ベンチマーク」で推奨設定を適用するか、プリセットを Performance / Low Latency にしてください。

**Q. 設定やログはどこ？** — インストール版は `%LOCALAPPDATA%\BetterGFNNeural`、ポータブル版は exe と同じフォルダです。「設定 → ログフォルダを開く」で開けます。ログには Windows のユーザー名やアカウント情報は記録されません。

## アンインストール

「設定 → アプリ → Better GFN Neural → アンインストール」またはスタートメニューの「Uninstall Better GFN Neural」。
「Windows 起動時に開始」の登録も削除されます。設定・ログを残すか削除するかを選べます。
